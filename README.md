# CareerBridge BRAC


## Introduction

CareerBridge BRAC is a PHP-based web application built to make recruitment and career management efficient and structured. It connects students and job seekers with companies offering jobs and internships through a single, centralized platform. By automating major recruitment tasks, the project reduces manual processing and improves transparency, accessibility, and decision-making accuracy.

- **Secure access:** users, companies, and administrators log in through session-based authentication.
- **Opportunity management:** companies can publish and maintain detailed job or internship listings.
- **Application tracking:** users can apply for opportunities and follow their application status in real time.
- **Eligibility and matching:** user qualifications (CGPA, skills, experience) are compared against opportunity requirements.
- **Probability analysis:** a review system processes these parameters into an overall probability score to support data-driven shortlisting.
- **Admin dashboard:** a control panel manages users, companies, applications, and analytics.

The project demonstrates the practical use of PHP, database management, and web technologies to solve real-world recruitment problems.

## Project Features


1. **User Registration and Login System**: frontend login/registration forms, plus PHP-based authentication, session handling, and secure login/logout.
2. **Opportunity Posting and Management**: frontend forms and tables, plus backend PHP logic for creating, updating, and deleting opportunities.
3. **Application Management System**: application submission and tracking interfaces, plus backend logic to store applications and manage their statuses.
4. **Eligibility and Matching Analysis**: frontend displays for eligibility results, plus PHP logic to evaluate CGPA, skills, and experience matching.
5. **Review and Probability Analysis System**: frontend pages showing probability scores, plus backend algorithms that calculate overall probability scores.
6. **Admin Dashboard and Control Panel**: the admin dashboard interface, plus backend PHP controls for managing users, companies, opportunities, and applications.

## Backend Development

User registration and login system, application management, and eligibility and matching analysis.
Opportunity posting and management, review and probability analysis, and the admin dashboard.


## Conclusion

CareerBridge BRAC shows how a PHP-based web application can manage recruitment and career opportunities in a structured and efficient way. The system integrates user registration and login, opportunity posting and management, application management, and an admin dashboard with a centralized control panel. The eligibility and matching analysis and the review and probability analysis system were added at a later stage, improving decision-making and candidate-opportunity alignment.

Overall, the project implements all intended features and provides a scalable foundation for future enhancements such as advanced analytics and automated notifications.
